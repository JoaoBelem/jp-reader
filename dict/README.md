# Dicionários locais

Coloque aqui o arquivo `.zip` de um dicionário compatível com Yomitan.

Não extraia o arquivo. O formato usa `index.json` e arquivos `term_bank_*.json` dentro do ZIP.

O leitor cria um índice local para pesquisar as definições. Feche e abra o app novamente depois de adicionar ou trocar um dicionário.
